# Command: /log

Record session work or a meaningful project change.

## Steps

1. Identify today's project note.
2. Record the work done, why it mattered, and the next action.
3. Include branch, commit, command/config, dataset, output path, and device/server when relevant.
4. If project status, blocker, latest useful result, or next action changed, update `memory/index.md`.
5. Keep source-code details brief; link to files, commits, or outputs when needed.
