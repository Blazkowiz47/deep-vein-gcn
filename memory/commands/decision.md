# Command: /decision

Record a project decision and rationale.

## Steps

1. Add a row to `memory/decisions.md` with date, decision, reason, consequence, and revisit condition if relevant.
2. Add a short entry to today's project note.
3. If the decision changes project status, blocker, latest useful result, or next action, update `memory/index.md`.
4. Preserve uncertainty. If the decision is tentative, mark it clearly.
