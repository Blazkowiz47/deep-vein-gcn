# Command: /run

Add or update an experiment, evaluation, or long-running job.

## Steps

1. Update `memory/runs.md` with date, device/server, branch/commit, command/config, dataset/input, output path, result, and next action.
2. Add a short entry to today's project note.
3. If the result changes the project's durable understanding, update `memory/learnings.md`.
4. If the run changes the current blocker or next action, update `memory/index.md`.
5. Avoid pasting raw logs; summarize and link to output paths.
