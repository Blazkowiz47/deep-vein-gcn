# Command: /status

Update the project context card and fast overview.

## Steps

1. Update the context card in `memory/index.md` first.
2. Keep `Status`, `Latest useful result`, `Current blocker`, and `Next action` current and specific.
3. Add a short entry to today's project note explaining what changed.
4. If the status update reflects a decision or durable learning, update `memory/decisions.md` or `memory/learnings.md`.
