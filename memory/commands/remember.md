# Command: /remember

Add a compact note to today's project memory.

## Steps

1. Identify today's local date and the active device/server.
2. Use `memory/notes/YYYY-MM-DD.md`, or `memory/notes/YYYY-MM-DD-<device>.md` when today's default note belongs to another device/server.
3. Append the note under the most relevant section, such as `Work Done`, `Analysis Results`, `Learnings`, `Blockers`, or `Next`.
4. If the note is durable, also update `memory/learnings.md`, `memory/decisions.md`, `memory/runs.md`, or `memory/index.md` as appropriate.
5. Keep the note compact. Link to evidence paths instead of pasting bulky output.
